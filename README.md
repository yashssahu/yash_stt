# Real-Time Speech-to-Text (STT)

Simple Chrome-based real-time speech-to-text web app.

Usage

1. Open `index.html` in Google Chrome (or Chromium).
2. Allow microphone access when prompted.
3. Click **Start** to begin continuous transcription (auto-restarts until you click Stop).
4. Use the right pane +/− controls to adjust the displayed text size.

Notes

- This app uses the Web Speech API built into Chrome. Accuracy depends on the browser's engine and microphone quality.
- To push these files to GitHub, follow the instructions in the repository or run the commands listed in `README` once you configure authentication.
